Что такое Daytona

Daytona — автономный ИИ-агент, который выполняет задачи по описанию: планирует шаги, работает с внешними инструментами и доводит работу до результата без постоянного контроля человека.

Возможности

  • Постановка задачи обычным текстом
  • Автономное планирование шагов
  • Работа с браузером и файлами
  • Интеграция с внешними сервисами через API
  • Логи выполнения и контроль результата
