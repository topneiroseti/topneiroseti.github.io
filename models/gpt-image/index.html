GPT Image 2.5

Разработчик: OpenAI

Категория: Изображения

Дата релиза: 8 сентября 2026

Версии API: Flare (быстрая) и Sunburst (премиум)

Разрешение: до 2K

Форматы: 1:1, 16:9, 9:16, 4:3

GPT Image 2.5 - новое поколение модели генерации изображений от OpenAI, выпущенное 8 сентября 2026 года. Модель создаёт более естественное освещение и насыщенные текстуры, лучше сохраняет субъектов с референс-фотографий и точнее следует инструкциям по редактированию через несколько итераций. Задержка генерации снижена до 50% по сравнению с GPT Image 2.0.

Каждую неделю через ChatGPT Images и GPT-Image в API создаётся более 3 миллиардов изображений. GPT Image 2.5 - следующий шаг: резче детали, быстрее генерация, точнее редактирование и новые инструменты для создания.

Ключевые возможности

  • Скорость: на 50% быстрее GPT Image 2.0. Flare - в 2-4 раза быстрее по данным Manus
  • Сохранение лиц: улучшенное перенесение черт с загруженных фото - узнаваемо тот же человек
  • Точечное редактирование: меняется только запрошенный элемент, остальное без изменений
  • Мульти-турн: качество сохраняется через несколько итераций правок без деградации
  • Прозрачный фон: надёжная генерация PNG с transparent background
  • Sketch: рисование прямо в ChatGPT как референс для финального изображения
  • Templates: шаблоны для популярных форматов - флаеры, продуктовые фото, обложки
  • Sharing: обмен промптами с другими пользователями

Частые вопросы

Что такое GPT Image 2.5?

GPT Image 2.5 - новая модель генерации изображений от OpenAI, выпущенная 8 сентября 2026 года. На 50% быстрее GPT Image 2, с точечным редактированием, Sketch и Templates.

Чем Flare отличается от Sunburst?

Flare - быстрая версия для большинства задач, в 2-4 раза быстрее GPT Image 2. Sunburst - премиум-версия с максимальной точностью редактирования, но дольше генерация. Обе стоят одинаково.

Как получить доступ из России?

Через российский агрегатор STIVA.ai - на странице stiva.ai/models/gpt-image-2-5. Оплата картой МИР и через СБП, без VPN.

Что такое Sketch в GPT Image 2.5?

Sketch - новая функция в ChatGPT. Рисуете скетч прямо в чате, и модель использует его как визуальный референс для финального изображения. Ввод: @Sketch в чате.
