GPT-6 Sol

Разработчик: OpenAI

Категория: Текст, кодинг, агентные задачи

Дата релиза: 22 сентября 2026

Model ID: gpt-6-sol

GPT-6 Sol - средняя модель в семействе GPT-6 от OpenAI, ниже флагманской Astra. Создана для сложных задач: кодинг, профессиональная работа, агентные сценарии. Обучена методами GPT-6 Astra - с переносом достижений в профессиональной работе, фактуальности, кодинге и computer use в более быстрый и доступный формат.

Контекстное окно 1.05M токенов, цена $2/$10 за 1M (на 50% дешевле GPT-5.6 Sol). На Terminal-Bench 4.0 набирает 66.4% - лучше всех моделей в своём классе. На DeepSWE v1.1 в пределах 1 процентного пункта от Claude Fable 5.1 при 80% меньшей стоимости за задачу.

Тарифы

  • API (входные): $2 / 1M токенов (-50% vs GPT-5.6 Sol)
  • API (выходные): $10 / 1M токенов (-50%)
  • Cached input: $0.20 / 1M (90% скидка)
  • Cache writes: $2.50 / 1M
  • Batch API: 50% от стандарта
  • Prompts >272K: 2x на input и cache

Частые вопросы

Чем GPT-6 Sol отличается от GPT-6 Astra?

Sol - средний tier в семействе GPT-6, ниже Astra. Создан для сложных задач: кодинг, профессиональная работа, агентные сценарии. Astra остаётся флагманом для самых требовательных проектов.

Сколько стоит GPT-6 Sol?

$2 за 1M входных токенов и $10 за 1M выходных. Cache reads - $0.20 за 1M с 90% скидкой.

Какой контекст у GPT-6 Sol?

1 056 000 токенов (1.05M), из которых 922 000 можно использовать на входе. Максимальный вывод - 128 000 токенов.

Все нейросети в одной подписке. GPT-6 Sol доступен через агрегатор STIVA.ai - 80+ моделей: текст, изображения, видео и аудио. Оплата картой МИР и через СБП, без VPN.
