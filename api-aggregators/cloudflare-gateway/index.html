Цены

  • Модель оплаты: бесплатно (core features) + Unified Billing (5% fee on credits) + Logpush (Workers Paid)
  • Комиссия: 0% на core features; 5% на Unified Billing credits (pass-through pricing от провайдеров)
  • Минимальный депозит: не применимо
  • Примеры цен:
  • Core features (analytics, caching, rate limiting): $0
  • Persistent logs: 100K (Free) / 10M per gateway (Paid)
  • DLP scanning: free
  • Guardrails: billed as Workers AI token-based
  • Logpush: 10M requests/мес, +$0,05/million (Workers Paid)
